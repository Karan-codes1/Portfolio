Full-stack / AI-powered learning platform

CareerPath

Live demo Source

A learning platform where people follow a career roadmap milestone by milestone, take quizzes and track their progress. I built both sides of it, a Next.js front end and a Node.js, Express.js and MongoDB back end with 30+ REST APIs.

Sign-in and roles
Google OAuth and credentials sign-in, with JWTs kept in httpOnly cookies. Middleware protects routes by role, and content management is admin-only.
Rate limits
Each user gets 20 calls an hour and 50 a day on the LLM endpoints, which keeps API cost under control. Failed logins are limited per IP address to block brute-force attempts.
Grading on the server
Quiz answers are scored on the server, and AI explanations are generated from database records, never from data the client sends.
Recommendations without invented links
An LLM pipeline works out a learner's weak concepts from their quiz mistakes, then selects resources only from candidates verified in the database. The model cannot return an invented or broken link.

Machine learning / End-to-end churn prediction

Customer Churn Predictor

Live demo Source

An end-to-end system that predicts which telecom customers are likely to leave, built on 7,043 customer records. The best model reaches 0.849 ROC-AUC, and it runs in the browser so every prediction is instant.

Data preparation
Exploratory analysis, missing-value handling, feature scaling and one-hot encoding of 16 categorical features.
Two models compared
Logistic regression and a random forest, trained on a stratified 80/20 split. Logistic regression performed best, with 0.849 ROC-AUC and 80% accuracy.
A threshold chosen on purpose
Lowering the decision threshold from 0.50 to 0.35 puts catching churners first. Recall rises from 57% to 72% and F1 from 0.60 to 0.63.
Shipped as a web app
The app on Vercel runs the model in the browser. It shows each customer's risk drivers, retention suggestions, and a live threshold and confusion-matrix explorer.
